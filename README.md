# ai_detect_for_sanqian

中文学术论文 AIGC 检测与去 AI 化改写 Skill，适用于 Claude Code / Cline / Cursor 等 AI 编程助手。

## 这是什么

一套专门针对**中文本科/硕士毕业论文**的去 AI 化指南和工作流。基于真实 AIGC 检测报告的逆向分析，总结出维普/知网检测器最容易捕获的写作模式，并提供**表面层 + 结构层两层同步改写**策略。

## 核心方法：五问检测法

对每个疑似段落问 5 个问题：

1. 有没有你系统**独有的**名词、参数、接口、表名？
2. 有没有至少一个**实测数值**或实验条件？
3. 有没有写清楚**为什么是这个机制带来了这个结果**？
4. 有没有**边界条件、例外情况**或适用范围？
5. 这段如果贴到**别人的论文**里，是否也几乎成立？

> 如果第 5 个问题答案是"是"，那这段就还不够好。

## 两层改写策略

有效的降重必须同时做两件事：

| 层次 | 内容 | 示例 |
|------|------|------|
| **表面层** | 替换AI化词汇、展开动词、增加辅助词、句式口语化 | "实现"→"得以实现"；"若...则..."→"要是...那就..." |
| **结构层** | 打破排比、删除万能句、加入边界条件、制造长短变化 | 三段式→自然段落；加"当倍率升至500×以上时..."等局限 |

## 检测到的 AI 痕迹类型

| 类型 | 危险度 | 说明 |
|------|--------|------|
| 工整排比 (1)(2)(3)(4) | ★★★ | 三段式并列 |
| 事实+解释节奏 | ★★★ | 每段都跟"这意味着……" |
| 标准化摘要/总结 | ★★★ | "问题→方法→结果→结论"四段式 |
| 等权重罗列 | ★★ | 所有技术点不分主次全列 |
| AI高频词（"值得注意的是"、"实现"、"基于"开头） | ★★ | 逐一替换表 |
| 每段长度均匀 | ★ | 制造长短段交替 |

## 安装

### Claude Code

```bash
# 方法 1: 克隆到项目 .claude/commands/
git clone https://github.com/houlaisan/ai_detect_for_sanqian.git .claude/commands/ai_detect_for_sanqian

# 方法 2: 用 skills CLI
npx skills add https://github.com/houlaisan/ai_detect_for_sanqian
```

### 其他 AI 编程助手

将 `SKILL.md` 复制到对应工具的 skills/commands 目录即可。

## 使用

在 Claude Code 中说：
- "降AI率"
- "去AI化"
- "检测AI痕迹"
- "扫描论文AI痕迹"

### 三种模式

- **模式 A（扫描）**：只诊断不改写，输出高危段落列表
- **模式 B（定向改写）**：根据检测报告标红段逐段改写，每段附改动说明
- **模式 C（全文润色）**：全文扫描 + 按危险度排序处理

- 硕士学位论文

## 不适用场景

- 英文论文（请用 [humanizer](https://github.com/blader/humanizer)）
- 非学术类文章（请用 [ai-flavor-remover](https://github.com/hylarucoder/ai-flavor-remover)）
